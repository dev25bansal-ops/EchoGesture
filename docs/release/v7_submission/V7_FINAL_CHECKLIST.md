# EchoGesture V7 — Final Checklist

Status: **NOT release-certified. Do not submit as an official package.**
This checklist records what is verified, what is blocked, and what must
not be claimed. Every "verified" box cites its artifact; every blocked
box names its gate and owner. The submission checklist in
`docs/hackathon/SUBMISSION.md` remains the organizer-input checklist —
this file is the V7 evidence gate over it.

## Verified (evidence in this copy)

- [x] **Evaluator contract runs.** `predict(video_path) -> dict` returns
  `clip_id`, uppercase `prediction`, `top5`, `confidence`, `latency_ms`
  (manifest runner, real ASL Citizen clips).
- [x] **Candidate identity pinned.** FP16 classifier `a012f2b5…7044a4`
  (832,888 B), detector `fbc2a300…cde1` (7,819,105 B), labels
  `e78f5028…01a4a` (100), features `baf28d05…aa84`, frontend
  `c73ef64b…97b0`. Total 8,651,993 bytes.
- [x] **Accuracy measured (N=346).** FP16 272/346 = 78.61% top-1
  (Wilson [73.99%, 82.61%]), top-5 89.31%; INT8 254/346 = 73.41%,
  top-5 86.13%. Paired on identical feature tensors.
- [x] **Training split leakage-audited.** Official val↔test signer overlap
  empty; supplied Dev train manifest disjoint from val and test
  (0 signer overlap, 0 clip overlap, 0 duplicate IDs); Dev claim
  cross-check all True.
- [x] **Latency measured (laptop).** N=30 V6 controlled: 231.48 ms p50 /
  306.55 ms p95; tracking p95 274.34 ms; classifier p95 0.12 ms.
  Doc aggregate 236.44 / 315.94 ms; regeneration 327.63 ms.
- [x] **Robustness measured (N=30 × 5).** low_light 3.33 pt PASS;
  crop 6.67 pt, occlusion 13.33 pt, motion_blur 13.33 pt,
  frame_drop 13.33 pt FAIL. Zero failed pairs anywhere.
- [x] **Rejected speedups documented** (cached VIDEO changed top-1;
  fresh VIDEO and image_cpu slower) — no unsafe optimization shipped.
- [x] **Provisional bundle builds and verifies** (13 members,
  extracted `WHATFOR1` prediction; official build fails by design).
- [x] **Test suite 161/161** passes (Python 3.11).
- [x] **Safety audit completed** with reproducible defects D1–D7 and a
  verified-safe offline/no-secret subset (code evidence only — not a
  compliance approval).
