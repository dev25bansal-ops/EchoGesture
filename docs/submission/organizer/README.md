| --- | --- |
| `int8-reply.pdf` / `.png` + `int8-reply.txt` | when the INT8 clarification is answered |
| `manifest-vocab-reply.*` | when the vocabulary/manifest question is answered |
| `submission-receipt.png` | after the Google Form is submitted |
| `submission-link.txt` | the actual submission form URL you were sent, with the date received |

## Rules

- Save the **raw** reply (PDF export or screenshot) plus a plain-text
  transcription; screenshots alone are hard to search later.
- Record the **date received** in the filename or in a line at the top of the
  text file. The compliance matrix cites this directory as evidence, and a
  citation without a date is not evidence.
- Do not edit a reply to remove anything. If it contains something we must not
  republish, keep the file private and note that here instead.
- This directory is inside the repository. If a reply contains the organizer's
  private address, a name, a phone number or the submission link's token,
  **do not commit it** — keep it local and record only the outcome.
